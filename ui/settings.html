日报

日报的生成、归档与查看在工作台里完成。这里是它的配置。

模型供应商

自动读取你在 Hana 里已配置的供应商。日报的编辑整理由你选定的模型完成。 App 不会接触任何 API Key。
读取中…
列表来自宿主目录。选中的模型 id 会原样传递，不做任何改写。

数据源

默认全部开启。中文优先指输出语言，不代表只抓中文源。 关掉的源不会参与抓取，也不会出现在日报的来源标记里。

内容

进入编辑层的条目数量上限。越多信息越全，但模型消耗越高。默认 40。
默认 24 小时。某源在窗口内不足 3 条时，该源会自动放宽到 48 小时。
